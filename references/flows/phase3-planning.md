# Phase 3：大纲与人物规划

## 目标

把创意变成结构化写作资产，确保后续创作有路线可走。

## 必须生成的文件

1. `00-人物档案.md`
2. `01-大纲.md`
3. `02-写作计划.json`
4. `追踪/上下文.md`
5. `追踪/伏笔.md`
6. `追踪/时间线.md`
7. `追踪/角色状态.md`

## 大纲要求

每章至少明确：

- 标题
- 核心事件
- 冲突或转折
- 章末钩子
- 人物弧光
- 字数目标

## 人物档案要求

主角、反派、核心配角至少要写清：

- 外部特征
- 目标
- 恐惧
- 动机链
- 关系张力
- 语言风格

## Hermes 执行建议

- 先产出粗纲，再让用户确认方向。
- 用户确认后再细化卷纲、细纲和追踪文件。
- 写作计划 JSON 要保持机器可读，方便后续自动续写和状态恢复。

## 通过标准

进入 Phase 4 前，必须让用户至少确认：故事方向没跑偏、篇幅合理、主角与核心冲突成立。
