# Phase 6：自动校验与修复

## 目标

在交付前把明显不达标的章节拦下来，减少逻辑断裂、注水和钩子失效。

## 校验维度

1. 字数是否达标
2. 情节是否连贯
3. 角色行为是否符合既有设定
4. 时间线是否冲突
5. 伏笔是否只埋不收
6. 章末钩子是否有效

## 修复策略

- 先定位问题类型，再决定局部修订还是整章重写。
- 同一章节最多重试 3 轮。
- 连续 3 轮不合格时，明确标记为“需人工干预”。

## Hermes 执行建议

- 先运行 `scripts/check_chapter_wordcount.py` 做硬性检查。
- 再按章节读取正文与追踪文件做语义一致性检查。
- 并行审稿时，最终要由主 Agent 汇总冲突并统一定稿。

## 最终输出

至少生成一份校验摘要，说明：

- 已通过章节
- 已修复问题
- 仍待人工处理的问题
