# Phase 0：初始化与偏好加载

## 目标

在正式创作前恢复用户偏好、检测当前工作目录是否已有未完成项目，并给出明确的起步分支。

## Hermes 执行要点

1. 优先从已安装 skill 目录读取 `user-preferences.json`。
2. 在当前工作目录查找 `02-写作计划.json`、`追踪/上下文.md`、`正文/` 等项目痕迹。
3. 如果检测到多个项目，先向用户列出候选项，再继续。
4. 如果没有历史偏好或没有未完成项目，直接进入 Phase 2 的问答流程。

## 推荐检查顺序

1. `user-preferences.json`
2. `02-写作计划.json`
3. `追踪/上下文.md`
4. `追踪/伏笔.md`
5. 最近一章正文

## 输出要求

- 明确当前是“继续创作”还是“开始新项目”。
- 给出本次将沿用的偏好摘要，例如题材、视角、单章字数、读者方向。
- 如果缺少偏好文件，不要卡住，直接按默认值继续。
