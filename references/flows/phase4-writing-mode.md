# Phase 4：写作模式选择

## 目标

根据项目规模和当前会话能力，选择最稳妥的执行方式。

## 模式说明

### 1. 串行

适合 10-30 章项目。由主 Agent 逐章完成，优先保证一致性。

### 2. 子Agent并行

适合 20-50 章项目。可将相邻章节拆成批次处理，但必须先共享完整大纲、人物档案和追踪状态，避免前后文打架。

### 3. Hermes 多代理协作

适合 30+ 章大型项目。使用 Hermes 的 `delegate_task` 做分工，例如：

- 一个子任务负责补卷纲
- 一个子任务负责撰写章节草稿
- 一个子任务负责审稿和一致性检查

## Hermes 执行边界

- `delegate_task` 适合有明确输入输出的子任务，不适合无限长创作。
- 章节并行时，必须按批次推进，不能把整本书同时发散出去。
- 任何子任务都必须拿到统一的大纲、角色状态和伏笔状态。

## 选择建议

- 用户没特别要求时，默认选串行。
- 需要赶进度且结构清晰时，再启用并行。
- 没有委派工具时，自动回退到串行，不阻塞任务。
