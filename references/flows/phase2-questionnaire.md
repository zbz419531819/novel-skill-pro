# Phase 2：三层递进式问答

## 目标

把模糊创意压缩成可执行的故事起点，避免一上来就盲写。

## Layer 1：核心定位

必须确认 3 件事：

1. 题材或故事核
2. 主角画像
3. 核心冲突

## Layer 2：深度定制

按需补齐：

- 世界观
- 叙事视角
- 整体基调
- 主题方向
- 目标读者
- 章节规模

## Layer 3：标题生成

- 至少给 5 个标题备选。
- 标题要区分男频、女频、悬疑、短篇等不同风格。
- 用户未选定时，先用工作标题继续，不阻塞后续流程。

## Hermes 执行建议

- 有 `clarify` 能力时，可逐问交互。
- 没有 `clarify` 能力时，可一次性列出问卷模板让用户填空。
- 用户若只给一句创意，也要先补齐最低必要信息，再进入大纲阶段。

## 输出要求

最终沉淀为一个清晰的创作简报，至少包含：题材、主角、冲突、风格、篇幅、标题候选。
